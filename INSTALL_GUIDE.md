# Installation Guide

Complete installation instructions for Chain-Breaker.

## Prerequisites

- Python 3.11+
- Git
- 10 GB free space

## Windows

### One-Click Installer
1. Download `install_easy.bat`
2. Right-click → Run as Administrator
3. Done!

### Manual Install
```cmd
git clone https://github.com/kaibuzz0/chain-breaker.git
cd chain-breaker
pip install -r requirements.txt
```

## Linux/Mac

```bash
git clone https://github.com/kaibuzz0/chain-breaker.git
cd chain-breaker
pip3 install -r requirements.txt
```

## Android (Termux)

```bash
pkg update && pkg install python git
git clone https://github.com/kaibuzz0/chain-breaker.git
cd chain-breaker
pip install -r requirements.txt
```
