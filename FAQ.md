# Frequently Asked Questions

## What is Chain-Breaker?

A distributed system for preserving ancient texts using blockchain and cryptography.

## Is it free?

Yes. Open source under MIT license.

## Do I need the private repo?

Public repo has demos. Private has all 73 texts.

## Can I add my own texts?

Yes, with the ingestion tools.

## Is it safe?

Yes. Uses SHA-256 and E8 quantum-resistant cryptography.

## Mobile support?

Yes, via Termux on Android.

## How much storage?

Full collection is ~650MB. Each node can choose storage limit.
