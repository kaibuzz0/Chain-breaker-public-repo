## 🎯 What is Chain-Breaker?

Chain-Breaker is a **distributed scripture preservation system** that:

- 📚 Stores biblical, apocryphal, and ancient texts

- 🌐 Distributes across a peer-to-peer network

## 🚀 Quick Start

### Option 1: Windows (Easiest)

1. Download `install_easy.bat` from this repo
2. **Right-click** → "Run as administrator"
3. Done! 🎉

### Option 2: Linux/Mac

```bash
# Install Python 3.11+ first, then:
git clone https://github.com/kaibuzz0/chain-breaker.git
cd chain-breaker
pip install -r requirements.txt
python vault_cli.py --list
```

### Option 3: Android (Termux)

```bash
pkg update && pkg install python git
git clone https://github.com/kaibuzz0/chain-breaker.git
cd chain-breaker
pip install -r requirements.txt
python vault_cli.py --list
```
