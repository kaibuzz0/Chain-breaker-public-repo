# 🎮 Chain-Breaker Games

Cheesy biblical desktop games!

---

## 📜 Scripture Scramble

**A word unscrambling game**

Unscramble biblical words and names!

**How to Play:**
- Look at the scrambled letters
- Type what you think the word is
- Get 10 right to win!
- Use hints if you get stuck

**Features:**
- 50+ biblical words
- Score tracking
- Streak counter
- High score saves
- Cool dark theme

**Run:**
```bash
python ScriptureScramble.py
```

---

## 🐍 Chain-Breaker Snake

**Classic snake game with a twist!**

Guide the snake to eat the holy scrolls!

**How to Play:**
- Use WASD or Arrow Keys to move
- Eat the 📜 scrolls to grow
- Don't hit walls or yourself
- Press SPACE to start

**Features:**
- Smooth controls
- Score tracking
- High score saves
- Cool dark theme

**Run:**
```bash
python ChainBreakerSnake.py
```

---

## 📖 Bible Memory Match

**Memory card game with verses**

Match the beginnings of famous Bible verses!

**How to Play:**
- Click cards to reveal verse parts
- Find matching verse beginnings
- Match all 12 to win
- Beat your best time!

**Features:**
- 12 biblical verses
- Timer and move counter
- Card flip animations
- Cool dark theme

**Run:**
```bash
python BibleMemoryMatch.py
```
