# Troubleshooting

Common issues and fixes.

## Python Not Found

**Windows:** Install Python from python.org, check "Add to PATH"

**Linux/Mac:** Use `python3` command

## Permission Denied

**Windows:** Run as Administrator

**Linux/Mac:** Use `chmod +x script.sh`

## Git Clone Fails

Use HTTPS: `git clone https://github.com/kaibuzz0/chain-breaker.git`

## Module Not Found

```bash
pip install --force-reinstall -r requirements.txt
```

## Still Stuck?

Open an issue: https://github.com/kaibuzz0/chain-breaker/issues
