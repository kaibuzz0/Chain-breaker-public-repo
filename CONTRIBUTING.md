# Contributing

How to help improve Chain-Breaker.

## Ways to Contribute

- Report bugs
- Suggest features
- Improve documentation
- Submit code
- Translate

## Submitting Changes

1. Fork the repository
2. Create a branch
3. Make changes
4. Test
5. Submit pull request

## Code Style

- Python PEP 8
- Clear comments
- Tests included

## Questions?

Open an issue on GitHub.
